## 자료 정의에서 확인한 범위

SKT 데이터정의서에는 다음 내용이 적혀 있습니다.

- OD 기간: 2023-09-01부터 2023-10-15
- OD 관측 단위: 출발 행정동, 도착 행정동, 날짜, 시간, 성별, 연령, 주 이동수단, 체류목적 조합
- OD 주요 값: 평균 이동거리, 평균 이동시간, 이동인원 `od_cnts`
- 체류인구 기간: 2023-09-01부터 2023-10-15
- 체류인구 관측 단위: 행정동, 날짜, 시간, 성별, 연령, 체류목적 조합
- 체류인구 값: 전국민 추정계수를 적용한 `stay_cnts`

버스와 지하철 30분 자료는 교통카드 거래내역을 출발 시간 기준으로 집계한 자료입니다. [버스 자료 안내](https://bigdata.seoul.go.kr/data/selectSampleData.do?sample_data_seq=72)와 [지하철 자료 안내](https://bigdata.seoul.go.kr/data/selectSampleData.do?sample_data_seq=71)는 상위 데이터인 "서울시 대중교통 및 지하철 1회권 승하차 데이터" 중 거래내역을 30분 단위로 집계한다고 설명합니다. [상위 데이터 안내](https://bigdata.seoul.go.kr/data/selectSampleData.do?r_id=P213&sample_data_seq=13)는 대중교통 거래내역과 지하철 1회권 자료를 별도로 구분합니다.

이 분석에서는 선정한 정류장·역의 승차 건수를 같은 자료 안에서 비교합니다. 별도 환산계수로 전체 이용 규모를 추정하지 않았으며, 승차 건수를 전체 방문객이나 고유 이용자 수로 해석하지 않습니다. 공간 결합에서 빠진 정류장과 중복 이름의 처리 범위는 [결합 검증표](../outputs/tables/join_audit.csv)에 남겼습니다.

TPSS의 `stop_count`는 노선·정류장·시간대별 운행횟수의 합입니다. 차량 대수, 좌석 수, 계획 배차 또는 실제 탑승 가능 인원과 같지 않습니다.

## 날짜 가용성

`inventory_local_source_dates`는 원자료 행을 읽지 않고 파일명과 TPSS 주간 파일 범위에서 날짜를 확인합니다.

| 자료 | 로컬에서 확인한 날짜 |
|---|---|
| SKT OD | 2023-09-01부터 2023-10-15, 45일 |
| SKT 체류인구 | 2023-09-01부터 2023-10-15, 45일 |
| 버스 30분 자료 | 2017-09-01부터 09-30, 2023-10-01부터 10-31, 총 61일 |
| 지하철 30분 자료 | 2017-09-01부터 09-30, 2023-10-01부터 10-31, 총 61일 |
| TPSS | 추출된 주간 파일 기준 총 98일 |
| 다섯 자료의 공통기간 | 2023-10-02부터 2023-10-15, 14일 |
| 공통기간의 토요일 | 2023-10-07 행사일, 2023-10-14 정상일 |

GIS는 날짜별 관측 자료가 아니라 공간 참조 자료이므로 공통기간 계산에서는 정적 자료로 취급합니다.

## 교통 운영계획 자료

서울시는 2023년 행사에 대해 여의동로 통제, 버스 우회, 일부 정류소 무정차, 귀가시간대 집중배차와 지하철 증회 계획을 발표했습니다.

- 여의동로 전면 통제: 14시부터 23시
- 여의동로 경유 20개 버스노선 우회
- 한강대교 경유 14개 노선의 일부 정류소 무정차: 16시부터 21시
- 여의도 관련 26개 버스노선 집중배차: 20시부터 22시
- 지하철 5·9호선 운행횟수 70회 추가 계획

출처: [서울시 2023 서울세계불꽃축제 교통대책](https://mediahub.seoul.go.kr/archives/2009223)

이 내용은 운영계획입니다. TPSS는 실제 시간대별 정차횟수 자료입니다. 현재 파이프라인은 운영계획과 실제 운행을 하나의 인과모형으로 결합하지 않았습니다.
