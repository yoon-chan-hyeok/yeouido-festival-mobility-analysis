# 모델 선택 기준

## 먼저 확인한 것

예측 목표는 여의도 출발 버스 통행의 시간대별 추가 이동시간입니다. 후보 feature는 출발 버스 OD 통행량, 체류인구, 버스·지하철 승차 관측치, TPSS 정차횟수, 시간대입니다.

그러나 다섯 소스가 모두 존재하는 날짜는 2023-10-07과 2023-10-14 두 날뿐입니다. 시간 행을 무작위로 나누면 같은 날짜의 패턴이 학습과 평가 데이터에 함께 들어갑니다. 점수는 만들 수 있지만 새로운 행사일을 예측하는 성능으로 해석할 수 없습니다.

이 저장소는 이런 이유로 예측 성능을 공개하지 않습니다. 데이터 가용성 판단은 `outputs/reports/model_readiness.json`에서 확인할 수 있습니다.

## 데이터가 더 확보됐을 때의 비교 순서

| 후보 | 역할 | 선택 기준 |
|---|---|---|
| Ridge | 기준 모델 | 계수 해석이 쉽고 상관된 feature의 영향을 완화할 수 있음 |
| Gradient Boosting | 주 후보 | 수요, 공급, 시간대 사이의 비선형 관계와 상호작용을 다룰 수 있음 |
| Random Forest | 비교 모델 | 비선형 관계에 대한 결과의 방향이 주 후보와 일관적인지 확인 |
| SVR | 추가 비교 | 표본이 늘어난 뒤 feature scaling을 적용해 비선형 경계를 비교 |

KNN은 시간대별 표본 밀도와 거리 척도에 민감해 우선순위를 낮춥니다. 단조 제약은 초과 교통량이 늘 때 지체가 감소하지 않는다는 가정이 여러 날짜의 검증 결과에서도 유지될 때만 적용합니다.

## 검증 방법

1. 날짜를 하나의 group으로 묶습니다.
2. 한 날짜의 모든 시간대를 통째로 평가 데이터로 남깁니다.
3. 정상 토요일 평균을 단순 기준값으로 둡니다.
4. 모델의 MAE가 기준값보다 낮은지 확인합니다.
5. 행사일이 여러 개 확보되면 행사일 전체를 별도 holdout으로 둡니다.

이 순서는 모델 종류보다 데이터 누수를 먼저 통제하기 위한 것입니다.
