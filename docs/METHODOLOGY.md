# Methodology

## 1. 분석 대상

- 사례: 2023년 10월 7일 서울세계불꽃축제
- 핵심 공간: 여의동 행정경계 내부와 여의도 출발·도착 서울 행정동 OD
- 핵심 시간: 18시부터 23시
- 비교 원칙: 행사일과 같은 요일인 토요일끼리 비교

## 2. 공간 범위

`seoul_dong_2017year_epsg5186`에서 여의동 폴리곤을 읽고, `TB_E_BUSSTOP_2019`의 정류장 포인트에 point-in-polygon을 적용했습니다. 결과는 59개 정류장 ID와 40개 고유 정류장명입니다.

버스 30분 자료는 정류장명 표기 차이를 줄이기 위해 공백과 기호를 정규화한 뒤 정확 일치로 범위를 선택했습니다. 같은 이름을 가진 여러 GIS 포인트는 여의도 전체 합계에는 포함하지만 임의의 좌표에 순서대로 배정하지 않았습니다. TPSS는 정류장 ID가 정확히 일치하는 경우만 사용했습니다.

## 3. 시간 집계

- 버스·지하철: 30분 행을 시간 단위로 합산
- TPSS: 원자료의 24개 시간대별 열을 시간별 정차횟수로 변환
- OD: 출발 통행은 `start_time`, 도착 통행은 `end_time` 기준
- 체류인구: 인구특성·목적별 행을 행정동·시간 단위로 합산

## 4. 정상 토요일 기준

OD·체류인구는 2023-09-02, 09-09, 09-16, 09-23, 10-14의 평균을 기본값으로 사용했습니다. 추석 연휴 기간인 09-30을 포함한 결과는 별도 민감도 표로 생성합니다.

10월 버스·지하철·TPSS는 2023-10-14, 10-21, 10-28의 시간대별 평균을 사용합니다. 서로 다른 자료의 비교 가능 날짜 범위가 다르므로, 통합 feature table에는 이 차이를 전제로 한 기술통계만 수록합니다.

## 5. OD 가중평균

각 OD 행에는 평균 이동시간과 추정 통행량이 함께 있습니다. 행 평균의 단순 평균은 통행량이 1인 행과 1,000인 행을 동일하게 취급하므로 다음과 같이 계산합니다.

```text
weighted_duration = od_duration_avg × od_cnts
weighted_average = Σ weighted_duration / Σ od_cnts
```

정상 토요일 이동시간은 날짜별 평균을 다시 평균하지 않고, 정상일에 포함된 OD 행의 `weighted_duration`과 `od_cnts`를 합쳐 pooled weighted average로 계산합니다.

## 6. 수요·공급 Stress Test

```text
load_t = bus_boardings_proxy_t / TPSS_stop_count_t
stress_t = event_load_t / normal_load_t
```

공급 회복 시나리오는 행사일 정차횟수가 평상시보다 적은 시간에 한해 평상시 평균까지 회복한다고 가정합니다.

```text
restored_supply_t = max(event_supply_t, normal_supply_t)
restored_stress_t = (event_demand_t / restored_supply_t) / normal_load_t
```

18~23시 합계도 동일한 방식으로 합계 수요와 합계 정차횟수에서 계산합니다. `stop_count`는 실제 차량 대수가 아니라 정류장별 정차 사건의 합계이므로, 결과를 증차 대수로 바꾸지 않습니다.

## 7. Join Audit

각 결합에서 원자료 행 수, 매칭 행 수, 기준 정류장 수, 관측 정류장 수, 중복 이름 행 수를 기록합니다. 매칭되지 않은 항목은 강제 보정하지 않고 제외 사유와 처리 원칙을 별도 표로 남깁니다.

## 8. 해석 범위

분석은 행사일과 정상 토요일의 동시 변화를 보여줍니다. 도로통제나 우회가 정차횟수 감소를 만들었다는 인과관계, 공급 회복이 이동시간을 얼마나 줄인다는 정책 효과는 추정하지 않습니다.
