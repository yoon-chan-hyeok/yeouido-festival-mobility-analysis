# Portfolio Guide

## 면접에서 말해도 되는 내용

- 동일 요일이 아닌 비교군을 발견해 행사일과 같은 토요일 기준으로 분석을 다시 구성했다.
- SKT OD 평균 이동시간을 `od_cnts`로 가중해 통행량이 반영된 pooled average를 계산했다.
- 18~23시 여의도 출발 버스 이동시간은 행사일 64.60분, 정상 토요일 32.62분으로 31.99분 높았다.
- 같은 시간대 버스 승차 관측치는 142.4%, 지하철 승차 관측치는 190.0% 높았고 TPSS 정차횟수는 37.4% 낮았다.
- 행정동 GIS로 정류장 59개를 추출하고 버스는 정규화 정류장명, TPSS는 정확한 정류장 ID로 결합했다.
- 중복 정류장명을 임의 좌표에 할당하지 않고 area aggregate로만 사용했으며 결합 성공률과 제외 사유를 audit 표로 만들었다.
- 여러 출처를 시간대별 feature table로 통합하고, 평상시 정차 공급 회복 시나리오를 설명적 stress test로 계산했다.
- 모든 출처가 겹치는 날짜가 두 개뿐임을 확인하고 예측 점수 공개를 보류했다. 날짜 전체를 holdout하는 검증 계획과 모델 후보를 따로 정리했다.
- `HALF_HOUR=30` 행이 빠지는 파싱 오류를 원자료 검산에서 발견해 수정하고 단위 테스트를 추가했다.

## 반드시 조건을 붙여야 하는 내용

- 버스·지하철 수치는 전체 승객수가 아니라 1회용 카드 기반 관측치다.
- 체류인구 합계는 고유 방문자 수가 아니라 시간대 관측치의 합이다.
- TPSS 정차횟수는 버스 대수나 좌석 공급량과 동일하지 않다.
- 이동시간에는 정류장 대기시간이 별도 변수로 분리되어 있지 않다.
- 행사일과 정상 토요일의 차이는 기술통계이며 인과효과가 아니다.

## 성과로 말하면 안 되는 내용

- 공덕·당산·노량진이 최적 셔틀 허브라는 주장
- 특정 차량 대수와 회차로 정해진 인원을 수송할 수 있다는 주장
- 대절 비용이나 비용편익이 검증됐다는 주장
- 셔틀 또는 증차가 이동시간을 정해진 분만큼 줄였다는 주장
- 도로통제·우회·무정차가 TPSS 감소의 원인이라는 확정적 주장

위 내용은 기존 발표에서 검토한 정책 아이디어이거나 추가 자료가 필요한 가정이며, 현재 재분석 결과에는 포함하지 않습니다.
