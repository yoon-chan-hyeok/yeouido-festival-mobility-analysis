# 다음 세션 인수인계

## 현재 공개본에서 확정한 내용

- 행사일은 2023-10-07 토요일입니다.
- 정상 비교군은 토요일만 사용합니다.
- SKT OD 이동시간은 `od_cnts`를 가중치로 사용한 pooled weighted average입니다.
- 버스·지하철 자료는 1회용 카드 기반 관측치이며 전체 승객수로 부르지 않습니다.
- TPSS는 노선·정류장·시간대별 정차횟수 지표이며 차량 대수나 좌석 공급량이 아닙니다.
- 수요 증가와 정차횟수 감소는 같은 시간대에 나타난 기술통계입니다. 인과관계로 해석하지 않습니다.
- 공급 회복 계산은 설명적 stress test입니다. 실제 증차 대수나 정책 효과가 아닙니다.

## 이번에 바로잡은 내용

이전 공개본은 분석 패널에 적재한 2023-10-07과 2023-10-14를 전체 원자료의 공통 날짜처럼 설명했습니다. 로컬 파일을 다시 조사한 결과 다섯 자료의 공통기간은 2023-10-02부터 10-15까지 14일입니다.

다만 공통기간의 토요일은 다음 두 날짜뿐입니다.

- 2023-10-07: 행사일
- 2023-10-14: 정상 토요일

따라서 14개 날짜로 날짜 단위 탐색은 가능하지만, 행사일 한 건으로 다른 행사의 예측 성능을 주장할 수 없습니다. `model_readiness.json`은 선택 패널 날짜와 로컬 원자료 날짜를 별도 필드로 기록합니다.

## 수상 경력 상태

로컬 문서와 서울시립대학교 공개 페이지에서 "교내 데이터 분석 프로젝트 우수상"의 공식 대회명, 주최, 연도, 상장 또는 수상자 명단을 확인하지 못했습니다.

다음 자료 중 하나를 확보하기 전에는 README와 이력서에 수상 경력을 추가하지 않습니다.

- 상장 이미지 또는 PDF
- 학교나 학과 공식 공지
- 공식 수상자 명단

`윤찬혁_빅콘테스트 자료.docx`와 SKT 데이터정의서는 대회 자료를 사용했다는 근거이지 수상 증빙이 아닙니다.

## 운영계획과 실제 관측

서울시 공식 자료에는 2023년 행사 당일의 통제, 우회, 무정차, 집중배차 계획이 있습니다. 이 정보는 `DATA_PROVENANCE.md`에 링크했습니다.

현재 분석에서 실제로 결합한 공급 자료는 TPSS 정차횟수입니다. TPSS 감소만 보고 우회, 무정차, 결행, 감차 중 어느 원인이 작용했는지 구분할 수 없습니다. 원인을 분석하려면 계획 운행표와 실제 BMS·AVL 차량궤적 또는 운행일지가 필요합니다.

## 의사결정 사용 시나리오

이 프로젝트가 지원하려던 결정은 서울시 행사 교통운영 담당자, TOPIS 운영 담당자와 버스 운영사의 사전 배차 검토와 사후 운영 점검입니다.

- 행사 종료 전후 어느 정류장과 노선의 공급이 부족했는지 확인
- 20시부터 22시 집중배차 계획이 실제 정차횟수 증가로 이어졌는지 점검
- 다음 행사에서 집중배차 시간과 대상 노선을 조정
- 행사 후 수요·공급 불균형을 정류장 단위로 감사

공덕·당산·노량진 셔틀 허브는 후속 아이디어입니다. 최적 입지나 정책 효과로 검증되지 않았습니다.

## 시각자료 상태

공개 저장소의 `outputs/figures/actual_*.svg`는 수정된 파이프라인에서 재생성한 결과입니다.

작업 폴더에는 다음 기존 자료가 남아 있지만 공개본에는 포함하지 않았습니다.

- `교통종합설계_판넬_윤찬혁_완성.pptx`, PDF와 preview PNG
- `여의도 환승거점 셔틀버스_윤찬혁.pptx`
- `seoul_new_data/outputs` 아래의 기존 Leaflet 지도와 HTML

기존 패널의 수송인원, 차량 대수, 회차, 시간절감과 거점 선정은 검증되지 않은 시나리오입니다. 기존 Leaflet 지도는 과거 정류장 매칭 범위와 30분 파싱 문제를 다시 점검한 뒤 사용해야 합니다.
